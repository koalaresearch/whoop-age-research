# Privacy Policy — WHOOP Age Research

**Last updated: October 10, 2026**

## 1. Purpose

WHOOP Age Research is a personal, non-commercial educational project created to study physiological age estimation using wearable data and publicly available scientific methods.

## 2. Data Accessed

With the account holder's authorization, the application may access WHOOP recovery, sleep, activity, workout, and body measurement data through the WHOOP API.

## 3. Data Use

Authorized data is used solely for personal scientific learning, exploratory analysis, and development and evaluation of physiological age estimation methods.

## 4. Storage and Security

The project is designed to process and store WHOOP data locally on the account holder's computer. API credentials and health records are not intentionally published in the project's public repository.

## 5. Data Sharing

The project does not sell WHOOP data or intentionally share identifiable health records with third parties. GitHub Pages is used only to host this informational privacy policy.

## 6. Data Retention and Deletion

Locally stored data may be retained for the duration of the research project and can be deleted by the account holder. API access can be revoked through the relevant WHOOP account authorization controls.

## 7. Changes

This policy may be updated if the project's data processing, storage, or sharing practices change.
